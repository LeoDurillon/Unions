# Map: `scripts/`

Repository scripts: database backup, restore and reset, the live-instance activity check, the doc link and map checks, moving files, changed-file lint, Union update, usage backfill.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `active.ts`: Says whether anything runs on the live instance; exits 1 if so (before editing worker/core files or restarting).
- `db-backup.ts`: The `db:backup` script: copies the SQLite database to a backup file.
- `db-in-use.ts`: Who has the database open: host processes and the compose web/worker services.
- `db-reset.ts`: The `db:reset` script: backs up and empties the database, refusing while it is in use.
- `db-restore.ts`: The `db:restore` script: replaces the database with a backup file, refusing while it is in use.
- `db-tools.ts`: Backs up, restores and resets the database, for the `db:*` scripts.
- `doc-links-lib.ts`: Finds the relative links of a markdown file and which of them point at no file: the doc-link check's pure part.
- `doc-links.ts`: Fails when a link in the docs, the user guide, AGENTS.md or README.md points at a file that does not exist, or a living doc names a source path that is gone.
- `lint-changed.ts`: Lints only the TypeScript files changed since the last commit, and new ones: seconds instead of the whole repository while working.
- `move-files-lib.ts`: Rewrites the relative imports of a source file after files moved: the move script's pure part.
- `move-files.ts`: Moves source files into a folder and rewrites every relative import to and from them; `bun scripts/move-files.ts <folder> <file>...`.
- `repo-map-folders.ts`: What each folder of the map holds, one sentence each, for the index `bun run map` writes.
- `repo-map-lib.ts`: What `bun run map` writes: an index of the folders, and a map of each folder with one line per source file.
- `repo-map.ts`: Writes `docs/map/`: an index of the folders and a map of each; `--check` fails when one is out of date.
- `test-preload.ts`: Runs before every test file (`bunfig.toml`): points attachments at a temporary folder, never the live one.
- `union-update-backup.ts`: The database copy an update takes before a commit that brings migrations, and the pruning of older ones.
- `union-update.ts`: Union's update, started by the worker in its own process: backs the database up when migrations come, fast-forwards to `<to>`, reinstalls if needed, then ends …
- `usage-backfill.ts`: The `usage:backfill` script: records the token usage and tool uses of the agent calls already in the log (`DB_PATH`, else the default database).
