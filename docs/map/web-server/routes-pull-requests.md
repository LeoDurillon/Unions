# Map: `apps/web/src/routes/pull-requests/`

Pull request routes: listing, import, review load, checks, commits, description, comment replies, agent review.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `pr-agent-review.ts`: A pull request under review's agent review: one pull request, or the stack it is in, checked and queued for the worker.
- `pr-checks.ts`: `/api/tickets/:id/pr-checks`: the pull request's CI checks from GitHub, and the failed ones given to the implementer.
- `pr-comment-replies.ts`: Replies to a pull request's comments, for a ticket and for a current review (`<review>/replies`).
- `pr-commits.ts`: `<review>/commits`: the pull request's commits, and one commit's files and patches, to read the change commit by commit.
- `pr-description.ts`: `/api/tickets/:id/pr-description`: the agent rewrites the PR's description into drafts the user edits.
- `pr-import.ts`: `/api/tickets/github-pull-request`: a ticket from an open pull request of the project's repository, on its branch.
- `pr-review-load.ts`: Loads what a pull request route needs: the review and its project, and the GitHub auth to act on them.
- `pr-review.ts`: `/api/projects/:projectId/pull-requests/reviews/:number`: a review's description, discussion, diff and comments.
- `pull-request-cache.ts`: The pull request lists (and stacks) last read from GitHub, per project and filter, in this process.
- `pull-request-listing.ts`: The Pull requests tab's read from GitHub: the pull requests and the repository's stacks together.
- `pull-requests.ts`: `/api/projects/:projectId/pull-requests`: the repository's pull requests and stacks, read from GitHub.
