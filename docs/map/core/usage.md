# Map: `packages/core/src/usage/`

Agent usage: tokens and tool calls recorded from the log, Claude limits, totals and summaries, findings, and the "Suggest improvements" prompt.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-tool-calls.ts`: Counts an agent call's tool uses from its stream-json lines: calls, errors, refusals and output size per tool key.
- `agent-tool-key.ts`: What an agent's tool call is about, for counting: the command family and shape, the file read, the skill or subagent.
- `agent-tool-record.ts`: Records an agent call's tool uses (`agent_tool_usage`) from its lines in `agent_log`, live or replayed from the past.
- `agent-usage-record.ts`: Records an agent call's usage from its `result` line in `agent_log`, live or replayed from the past.
- `agent-usage-totals.ts`: What a ticket's or an investigation's agent calls used, per run and per call, summed for the Usage tables.
- `agent-usage.ts`: Reads what a `claude -p` call consumed from its stream-json events: tokens per model, and its peak context.
- `claude-limits.ts`: How much of the Claude subscription's usage windows (five hours, seven days) is used.
- `project-findings.ts`: Reads a project's agent calls, tool uses and change sizes over a range of days, and says what they show to improve.
- `project-usage.ts`: Reads a project's agent usage (its tickets' and its investigations') over a range of days, summed for its Usage page.
- `size-findings.ts`: The usage finding on change sizes: tickets whose first implementation went far over the plan's estimate.
- `tool-findings.ts`: What a project's agents' tool uses say to improve: large outputs, many forms of the checks, files read again, refusals.
- `usage-findings.ts`: What a project's agent usage says to improve: large sessions, costly tickets, many review rounds.
- `usage-suggestion-prompt.ts`: The prompt of a "Suggest improvements" investigation: the project's usage findings as figures, and what to answer.
- `usage-suggestion-rules.ts`: The "Suggest improvements" prompt's account of how Union runs the agents.
- `usage-suggestion.ts`: Queues a "Suggest improvements" investigation of the project's usage findings over a range.
- `usage-summary.ts`: A project's agent usage summed several ways for its Usage page: in all, per week, per step, per model, per ticket.
