# Map: `packages/core/src/flow/`

Ticket flows: the steps a ticket runs, the project's presets, editing them, step titles.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `flow-edit.ts`: Editing a flow in the settings or a ticket's Custom flow: planning steps on or off, custom agents added and moved.
- `flow-settings.ts`: A project's flow presets as the settings send them, checked: unique ids and names, valid steps, a default among them.
- `flows.ts`: Ticket flows: the steps a ticket runs, the presets a project offers, and what agents are told of skipped steps.
- `step-titles.ts`: A step's name as the UI, the notifications and the issue comments show it: built-in, or the custom agent's.
- `ticket-flow.ts`: Choosing the steps a ticket runs: only before it starts, since the start fixes them.
