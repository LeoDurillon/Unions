# Map: `packages/core/src/setup/`

The setup agent offered at the end of the wizard: its prompt, its proposal's parts and preview, and applying it.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `setup-agent.ts`: Queues the setup agent (a repository investigation of kind `setup`) and reads a project's latest one with its proposal.
- `setup-apply.ts`: What applying each section of a setup proposal makes of the project's settings, and whether it already matches; browser-safe.
- `setup-guide.ts`: Puts Union's user guide in a setup run's container, beside the repository, so the agent reads how each setting works.
- `setup-prompt.ts`: The setup agent's prompt: where Union's guide is, what to read, how each setting works, and the answer block to end with.
- `setup-proposal-parts.ts`: Readers for the setup agent's answer block: texts, lists and names, each refusal noted instead of thrown.
- `setup-proposal-preview.ts`: Reads the preview part of the setup agent's answer: compose file, served services, plain variables, secrets' names.
- `setup-proposal-types.ts`: What the setup agent proposes for a project's settings, section by section, as Union reads it back; browser-safe.
- `setup-proposal.ts`: Reads the setup agent's answer into a proposal: its final `json` block, each value checked, refusals listed.
