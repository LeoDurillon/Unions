# Map: `packages/core/src/lessons/`

The project's memory: lessons and feedback, the lesson writer and tidier, their prompts and queue.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `lesson-input.ts`: The lessons a Memory page save sends, checked, and the lesson writer's proposals applied to them (browser-safe).
- `lesson-prompts.ts`: The default prompts of the lesson writer and the lesson tidier (the parts the user can edit).
- `lesson-suggestions.ts`: The lesson writer's queue: a run asked from the Memory page, claimed by the worker, then accepted or dismissed.
- `lesson-tidier.ts`: The lesson tidier: the prompt it gets over a project's lessons, and its answer read back.
- `lesson-writer.ts`: The lesson writer: the prompt it gets for some feedback, what it shares with the tidier, its answer read as lessons.
- `lessons.ts`: The project's memory: lessons (rules per agent step, sent to that step's runs) and the feedback they are curated from.
