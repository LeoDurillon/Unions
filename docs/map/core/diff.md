# Map: `packages/core/src/diff/`

Diffs: parsing, hunks, excerpts, the links agents cite, and change size against the budget.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `change-budget.ts`: A ticket's size budget and whether a change goes over it.
- `change-size.ts`: How much code a change adds: its lines added outside tests and generated files.
- `diff-excerpt.ts`: The text of lines on one side of a file's patch, and the part of a range a line comment can take.
- `diff-hunks.ts`: A file's patch as hunks: the grouping by spec places hunks, the review page shows some of them.
- `diff-links.ts`: The diff a review agent's `path:line` reference opens: a changed file, at some lines of its new version; browser-safe.
- `diff.ts`: Unified diff parsing (output of `git diff`).
