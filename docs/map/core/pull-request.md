# Map: `packages/core/src/pull-request/`

A ticket's pull request: description rewrites, comment replies, review verdicts, branch moves on GitHub, the followed base, resumed-implementer prompts.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `branch-move.ts`: When a ticket's branch moved on GitHub away from what Union last pushed, and what that holds back until a resync.
- `branch-moves.ts`: What Union knows of the ticket's branch on GitHub: the commit it last pushed, a move away from it, and a resync onto it.
- `followed-base.ts`: When the ticket's pull request targets another branch on GitHub than the ticket's base: the base to follow.
- `pr-comment-reply.ts`: A reply to a pull request comment, as the web queues it and the worker posts it; browser-safe.
- `pr-description-outdated.ts`: Whether a pull request's description may be out of date: the branch was pushed after Union last wrote it.
- `pr-descriptions.ts`: Rewrites of a ticket's PR description: queued, run, drafted, sent to GitHub, and recovered after a stop.
- `pr-prompts.ts`: The default prompts of the turns that resume the implementer on its branch: trim, pull request replies, stack split.
- `pr-review-verdicts.ts`: What a review posted on GitHub says of the pull request: a comment, an approval, or a request for changes.
