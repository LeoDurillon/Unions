# Map: `packages/core/src/agent/`

The agents' defaults and how a run resolves them: prompts, models, tools, denied commands, environment, connectors, log, answer formats.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-activity.ts`: What an agent says or does in one `claude -p` stream-json event, in a short line.
- `agent-denied.ts`: The commands Union denies its agents, whatever their tools or the repository's settings: for every run, and per step.
- `agent-environment.ts`: The agent's environment settings as sent (`agentVariables`, `forwardPorts`, `startForImplementation`), checked.
- `agent-log.ts`: Writes the agents' output to `agent_log`, and reads a Log: events and agent lines in one order.
- `agent-tools.ts`: The tools agents run with: the defaults, Claude Code's built-in ones, and the list the user adds to.
- `agents.ts`: The agents' default prompts, models, efforts and tools, the user's overrides, and how a run resolves them.
- `default-prompts.ts`: The built-in agents' default prompts, as a run gets them until the user edits one.
- `diagrams.ts`: How agents draw diagrams in their answers: Mermaid code blocks, which Union and GitHub both render.
- `json-block.ts`: Finds the answer block at the end of an agent's text: the last fenced `json` block of the expected shape; browser-safe.
- `mcp-connectors.ts`: The account's claude.ai connectors: their tool rules and hints, and the checks that read them (`claude mcp list`).
- `prompt-formats.ts`: The formats Union reads back that only an agent's editable prompt asks for, and which of them a prompt dropped.
- `run-progress.ts`: What each running agent of a project is doing now: the last thing it wrote or the last tool it called.
