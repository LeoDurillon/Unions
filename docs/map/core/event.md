# Map: `packages/core/src/event/`

Event rules: the events catalog and payloads, the rules and their actions (Jira, Notion, GitHub Project fields, pull requests), cursors and deliveries.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `delivery-outcome.ts`: What doing a rule's action came to: done, skipped and why, failed, or to try again later.
- `event-action-checks.ts`: A rule's action as sent by the settings page, checked: GitHub's and Union's here, a tracker's by its tracker.
- `event-actions.ts`: The kinds of event rule action and what each holds; browser-safe, for the settings page and the worker.
- `event-catalog.ts`: The event log's types: a typed event to write, and a guard that narrows an event read back.
- `event-cursors.ts`: Readers that follow the event log (the rule deliveries, the notifications) and how far each got.
- `event-deliveries.ts`: Reads the events logged since the last call and queues one delivery per matching enabled rule.
- `event-legacy-actions.ts`: The rule action kinds before tracker actions (`notion_property`, `jira_*`), read as the tracker action each became.
- `event-payloads.ts`: What each type of event in the log carries, keyed by its `type`: the one place to add an event.
- `event-project-fields-action.ts`: A rule's GitHub Project fields: on the ticket's issue item or its pull request's, their checks and the values sent.
- `event-pull-request-action.ts`: A rule's changes to the ticket's pull request (labels, reviewers, assignees, title, a description section).
- `event-rule-error.ts`: A rule the checks refuse (unknown trigger or variable, missing field); its message is the user's to fix.
- `event-rule-types.ts`: Event rules: when something happens to a ticket, do something elsewhere.
- `event-rules.ts`: Event rules: checking and saving them, and matching events and templates.
- `event-tracker-actions.ts`: The rule actions on a tracker's item (move it, set its fields, comment on it), each naming its tracker; browser-safe.
