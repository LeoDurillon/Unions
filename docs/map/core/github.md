# Map: `packages/core/src/github/`

GitHub: auth and clients, the optional layers (Project, issues), Project fields, text, issue step comments, file blobs, half-sent recovery.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `github-auth.ts`: How a project reaches GitHub: the stored GitHub App, and the credentials `projectGitHubAuth` resolves.
- `github-client.ts`: One client per credential, kept for the process: an installation client mints its own short-lived token (one hour).
- `github-layers.ts`: Which optional GitHub layers a project uses: its GitHub Project (the board) and issues mirroring its tickets.
- `github-project-fields.ts`: Reading a GitHub Project's fields (the ones a rule can set) and setting one on an item.
- `github-sends-recovery.ts`: What a stopped worker left half-sent: a pull request review and replies marked `sending`.
- `github-text.ts`: Browser-safe: the PR tab shows GitHub text with it, and the import stores it.
- `issue-step-comments.ts`: Reads back the step comments Union wrote on a GitHub issue, to prefill a ticket imported from its pull request.
- `project-url.ts`: Parses `https://github.com/orgs/<login>/projects/<n>` (or `users/`).
- `repository-blob.ts`: How the Repository tab shows a file read from GitHub: text, an image, or only its size (binary, too large).
