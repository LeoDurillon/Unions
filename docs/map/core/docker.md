# Map: `packages/core/src/docker/`

Docker: the `ContainerRuntime` interface and the `docker` CLI behind it, helper containers, limits, compose containers, the projects' agent images.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-image-source.ts`: A project's own agent image: the Dockerfile or image the user gives, checked and rewritten onto the base images.
- `agent-images.ts`: A project's own agent image in the database: saved by the web, then built, applied or failed by the worker.
- `compose-containers.ts`: Reads `docker ps` lines of a compose project's containers, and which of its exposed services stopped.
- `container-init.ts`: Identifies this container's run: its init's (PID 1) start in clock ticks.
- `container-limits.ts`: The caps of a container on the docker command line: its memory, the CPU cores it may use, how many processes it runs.
- `copied-file.ts`: Checks a file copied out of a container before the host reads it: a regular file, within a size.
- `docker-cli.ts`: The container runtime that drives the `docker` command line to run ticket containers.
- `docker-helper.ts`: The `docker run` arguments of a throwaway helper container, and its removal when its work is aborted.
- `docker-images.ts`: The image runtime on the `docker` command line: the projects' own agent images, built, pulled, inspected and removed.
- `merged-lines.ts`: Lines from several byte streams as one, in the order they arrive: a command's stdout and stderr together.
- `runtime.ts`: Everything the worker needs from Docker.
