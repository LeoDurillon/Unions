- `use-ci-rerun.ts`: Asks the worker to run a failed GitHub Actions job again, and remembers it was asked until GitHub shows the new run.
- `use-commits.ts`: The change's commits, oldest first, and (tickets) the change since the last review.
- `use-compact-sidebar.ts`: Whether the sidebar is folded to an icon rail, remembered in this browser; folded at first on a narrow window.

- `use-dismiss.ts`: Closes a popup (a menu, a picker) on Escape or a click outside the element that holds it and its button.
- `use-event-stream.ts`: Calls `onEvent` with every new event, from the browser's one shared stream (`event-hub.ts`).
- `use-explanations.ts`: The review's explanations, polled while one waits or runs, with asking, following up and cancelling.
- `use-folded-columns.ts`: Which board columns are folded to a narrow strip, remembered in this browser; Merged / Closed starts folded.
- `use-github-app.ts`: The global GitHub App's status; saving or removing it invalidates `['github-app']`.
- `use-jira-comments.ts`: The comments of a ticket's Jira issue, read from Jira once per opening of its tab, and the comments sent to it.
- `use-jira-picks.ts`: What a Jira field rule can pick (people, versions, components, sprints), read from Jira when a field of that type is in the editor.
- `use-jira-review-import.ts`: Add to review on a Jira comment: the server reads it again and adds it to the ticket's review as a draft.
- `use-live-invalidation.ts`: Refetches board, ticket, investigation and notification data whenever the worker records a change.
- `use-log.ts`: Polls a ticket's or an investigation's Log while it is shown: all of it first, then what is new.
- `use-memory.ts`: The Memory page's data: lessons and feedback, saving them with the on/off switch, curating feedback, and the lesson writer's and tidier's runs.
- `use-models-form.ts`: The Models page's form: every agent's model and effort, each changed one saved with its prompt and tools as they are.
- `use-navigation.ts`: Which page is shown (`?page=previews`, `?union=` for the Union settings, else the board) and which overlay is open.
- `use-notifications.ts`: The notifications, page by page, with the unread count (also in the tab's title) marking them read and clearing them.
- `use-notion-comments.ts`: The open discussions of a ticket's Notion page, read from Notion once per opening of its tab, and the comments sent to it.
- `use-notion-review-import.ts`: Add to review on a Notion discussion: the server reads it again and adds it to the ticket's review as a draft.
- `use-notion-users.ts`: The Notion workspace members, read only when `enabled` (a person property is in view).
- `use-now.ts`: The current time, read again every second while `ticking`: for clocks that count while something runs.

- `use-pr-replies.ts`: The replies of one pull request (pending, suggested, who posts) and their mutations; the discussion is read again once GitHub has a reply.
- `use-preview.ts`: A ticket's or a pull request's preview as its section reads it, and the commands that act on it.
- `use-queued-work.ts`: Work the worker finishes later: the request is sent, then waited on until the ticket's done or failed event comes in.
- `use-review-agents.ts`: The review agents a review page can run, each one's newest run on the change, and running or cancelling one.
- `use-review-data.ts`: What a review page reads and writes: the diff, the comments and their writes, the picked slice of a split ticket, and the wording for the target.
- `use-review-grouping.ts`: The newest grouping by spec of the review, with starting and cancelling one.
- `use-review-jira.ts`: The Jira issues of a pull request under review: their text and comments, the suggestions, checking, linking, unlinking.
- `use-review-notion.ts`: The Notion pages of a pull request under review: their text, the description's suggestions, checking, linking one more and unlinking one.
- `use-review-preview.ts`: A pull request's preview as its Preview tab reads it (its checkout, its screenshots), and adding an output to the review.
- `use-review-report.ts`: The newest spec report of the review, with starting and cancelling one, adding its gaps to the review, and marking what needs the reviewer not useful.
- `use-review-specs.ts`: A review's specs (its Specs bar): the list as saved and read now, saving it, the specs the agents get, and a whole stack's for its agent review.
- `use-review.ts`: A pull request under review: its description and discussion, read from GitHub once per opening.
- `use-run-agent.ts`: What a ticket's command output can do with the implementer: wait for its next run, or go now as a revision.

- `use-running-previews.ts`: The previews running across projects (read again every few seconds: a pull request's send no events), and stopping one.

- `use-settings-form.ts`: A settings page's form: what is edited, whether it differs from what was saved, and its one Save.

- `use-start-output.ts`: The lines a ticket's preview prints while it starts (its build, its services), as they arrive.

- `use-usage.ts`: What agent calls used: a ticket's or an investigation's (refetched with them), a project's over a range of days, and how much of the Claude subscription's wind…
