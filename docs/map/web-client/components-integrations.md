# Map: `apps/web/client/components/integrations/`

The integrations step and sections: the GitHub Project, the trackers, importing from a source.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `disconnect.tsx`: The Disconnect button of a tracker's settings section: drops the integration and its secret at once.
- `github-project-picker.tsx`: Picks the GitHub Project a project's board mirrors to: one of the repository owner's, or a new one by title.
- `github-project-section.tsx`: Project settings → Integrations → GitHub Project: the board the tickets mirror to, connected, changed or disconnected.
- `integrations-step.tsx`: The setup wizard's Integrations step: a selector between the GitHub Project and the trackers (Notion, Jira).
- `source-import.tsx`: Fetches an item of a tracker the project is connected to (a Notion page), previews it, and creates the ticket.
- `tracker-section.tsx`: A tracker's project settings section, by kind (Notion, Jira).
- `tracker-verify.tsx`: The onboarding steps' Verify for a tracker: checks its secret and config, and keeps the normalized config and title.
