# Map: `apps/web/client/components/layout/`

The app's frame: the main area and its lazy pages, the project bar and body, the sidebar and its parts, dialogs, help and shortcuts, the wizard host.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `app-dialogs.tsx`: The dialog opened from the project bar: New ticket.
- `global-page.tsx`: The pages of the main area that belong to no project: the running previews and the user guide.
- `help-menu.tsx`: The sidebar's Help: a menu showing the getting-started checklist again, the user guide and the keyboard shortcuts.
- `lazy-pages.tsx`: The heavy pages, loaded only when first opened (the review page, both settings, usage, the guide).
- `main-area.tsx`: Right-hand side of the app: running previews, the guide, Union or project settings, or the project.
- `project-bar.tsx`: Slim bar above the project: which project is open, its tabs, and the actions.
- `project-body.tsx`: The open view of the project: board, investigations, pull requests, repository, environments or usage.
- `shortcuts-help.tsx`: The keyboard shortcuts: `?` (or the Help menu) lists them anywhere, c writes a new ticket from the board.
- `sidebar-classes.ts`: Classes the sidebar's entries use to fold into its icon rail (`data-compact` on the sidebar).
- `sidebar-entries.tsx`: The sidebar's projects (with Add project) and its Union settings entry.
- `sidebar-footer.tsx`: The foot of the sidebar: the live connection's state, Claude usage, and Union's Update.
- `sidebar.tsx`: The left sidebar: notifications, running previews, the project switcher and creation entry point, settings, Help.
- `stream-pill.tsx`: The sidebar's "Reconnecting…" pill, shown while the live event stream is down for more than a moment.
- `wizard-host.tsx`: The setup wizard: unavoidable on first run, dismissible when adding another project.
- `workspace.tsx`: Project bar plus the board, investigations, pull requests, repository or usage.
