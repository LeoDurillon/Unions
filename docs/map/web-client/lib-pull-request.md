# Map: `apps/web/client/lib/pull-request/`

A pull request's data: description rewrites, replies, CI checks and reruns, commits, stacks, importing one, the reviews without a ticket.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `pr-description-api.ts`: The browser's client for a ticket's pull request description endpoints; `pr` picks a slice's draft.
- `pr-import-api.ts`: Importing a pull request of the project's repository as a ticket: its preview, then the ticket.
- `pull-request-stacks.ts`: Stacks in the Pull requests tab and its Under review part, by GitHub's stacks.
- `use-ci-rerun.ts`: Asks the worker to run a failed GitHub Actions job again, and remembers it was asked until GitHub shows the new run.
- `use-commits.ts`: The change's commits, oldest first, and (tickets) the change since the last review.
- `use-current-reviews.ts`: The pull requests under review without a ticket, and adding or removing one.
- `use-pr-checks.ts`: A pull request's CI checks (the ticket's or a slice's), and giving picks of them to the implementer.
- `use-pr-description.ts`: A pull request's description rewrite: its latest draft, and rewriting, sending, discarding or cancelling it.
- `use-pr-replies.ts`: The replies of one pull request (pending, suggested, who posts) and their mutations.
- `use-stack-checks.ts`: The CI of a split ticket's open slices, read from GitHub when the PR tab opens and every 30 s while a check runs.
