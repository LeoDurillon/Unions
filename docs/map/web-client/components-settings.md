# Map: `apps/web/client/components/settings/`

A project's settings page: its sections (flows, scripts, checks, size, files, memory and lessons, agent image, GitHub access, issues, pull requests, events and rules), nav and save bar.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `action-fields.tsx`: What a rule does: the kind of action, then that kind's own fields.
- `action-kind-select.tsx`: The rule editor's "Then": the kinds of action the project can use (a tracker's only once it is connected).
- `agent-image-form.tsx`: The Agent image page's form: the default image, a Dockerfile built on it, or an image built elsewhere.
- `agent-image-section.tsx`: Project settings → Agent image: what the agents run on now, then the image to build for them.
- `agent-image-starters.tsx`: The agent image page's Dockerfile fields: the project's (highlighted, with "Start from") and the default image's.
- `agent-image-status.tsx`: The agent image page's state: what the agents run on, the save being built or why it was not applied.
- `agent-section-body.tsx`: The Agents group of the project settings: instructions, memory, checks, change size, scripts, flows and the agent image.
- `branch-section.tsx`: The project settings section for the base branch, saved with the General page's Save.
- `checks-section.tsx`: How the implementation agent's work is installed and checked inside the ticket's container.
- `delete-section.tsx`: Typing the repository name to confirm keeps a stray click from deleting a project.
- `delivery-list.tsx`: What the event rules did lately, as a table: when, status, rule and ticket, then what it set or why it failed.
- `delivery-row.tsx`: One row of Event activity: when, status, rule and ticket, then what it set or why it failed.
- `events-section.tsx`: Event rules: when something happens to a ticket, set a property of its Notion page or comment on GitHub.
- `feedback-inbox.tsx`: The feedback given on Revise and final reviews: made a lesson, given to the lesson writer, or dismissed.
- `files-section.tsx`: Files every ticket's workspace gets at a path in the repository, kept out of git.
- `flow-preset-row.tsx`: One flow preset in the settings: its name, what it is for, its planning steps and custom agents.
- `flows-section.tsx`: The project's flow presets: the steps a ticket can run, and the one new tickets get.
- `github-access-section.tsx`: The project settings section that shows and changes how the project reaches GitHub.
- `github-comment-fields.tsx`: A GitHub comment action's fields: the issue or the pull request, and the comment as a template.
- `instructions-section.tsx`: The project's own instructions, sent to every agent run on it after the shared instructions.
- `integration-section-body.tsx`: The trackers' settings pages, events and the danger zone.
- `issues-section.tsx`: Project settings → General: whether new tickets get a GitHub issue, always on while a GitHub Project is connected.
- `lesson-card.tsx`: One lesson as a card: its whole rule, wrapped; the pencil opens a multiline field to edit it.
- `lesson-list.tsx`: The project's lessons by agent step (and the spec report's), as cards.
- `lesson-suggestions.tsx`: The lesson writer's or tidier's latest run on the Memory page: working, failed, or its proposals.
- `lesson-tidy.tsx`: "Tidy lessons" on the Memory page: asks the lesson tidier to fix the lessons kept, then shows its proposals.
- `lessons-panel.tsx`: The Memory page's lessons part: whether they are sent to the agents, Tidy lessons, then the lessons by step.
- `memory-section.tsx`: Project settings → Memory: the lessons each agent step gets, and the feedback they are made from.
- `name-picker.tsx`: Picks names (labels, GitHub logins): the picked ones as chips, and a box that suggests the others and takes new ones.
- `people-field.tsx`: A person property: a box per workspace member; the value is their Notion ids.
- `project-field-row.tsx`: One field a Project fields rule sets: which field of the GitHub Project, its value, and removing it.
- `project-fields-fields.tsx`: A Project fields action's fields: the item (the issue's or the pull request's), then the fields to set, a row each.
- `project-file-list.tsx`: The project files already uploaded, each with its size, when it changed, and remove.
- `project-section-body.tsx`: The project's own settings, its GitHub Project and its pull requests'.
- `pull-request-change.tsx`: One change a pull request rule makes: labels, reviewers or assignees to pick, or a title or description template.

- `review-section.tsx`: Files the review page lists apart (collapsed), so the sidebar shows what needs reading.

- `size-section.tsx`: Project settings → Change size: the budget of a ticket whose plan gives no estimate, and the paths that are not code.

- `tracker-bars.tsx`: Above the event rules: each connected tracker's columns or fields as Union last read them, and reading them again.
- `tracker-preview.tsx`: A tracker action's preview on one ticket: what it would do on the item, with what only the run can check.
- `trigger-fields.tsx`: The "When" of an event rule: what triggers it, and the column, step or verdict some triggers need.

- `variable-chips.tsx`: The template variables as chips: clicking one adds it to the text being written.
