# Map: `apps/web/client/lib/review/`

The review's data: API clients and hooks for the review, specs, explanations, groupings, reports, agent reviews, preview and tracker links.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-review-api.ts`: API calls for a review's agent review, under the review's API root (`reviewBase`).
- `explanation-api.ts`: The explanation routes of a review, under its API root (`reviewBase`).
- `file-filter.ts`: Narrows the review's changed files: by words of their path (or their old path), and to the files Union counts as code.
- `review-agents-api.ts`: API calls for a review's review agents, under the review's API root (`reviewBase`): the agents it can run, each one's newest run, run one, cancel.
- `review-grouping-api.ts`: API calls for a review's grouping by spec, under the review's API root (`reviewBase`).
- `review-report-api.ts`: API calls for a review's spec report, under the review's API root (`reviewBase`).
- `review-stack.ts`: The stack a pull request under review is in, for the review page's agent: its pull requests bottom first, null when alone.
- `review-target.ts`: Where the target's diff, comments and send live; also the root of its query keys.
- `review-url.ts`: The review page's slice and section tab in the URL (`?slice=2&tab=pull-request`), the lines its diff opens on (`?lines=new:12-30:src/a.ts`), and the pull reque…
- `use-agent-review.ts`: The latest agent review of the target, with starting and cancelling it.
- `use-explanations.ts`: The review's explanations, polled while one waits or runs, with asking, following up and cancelling.
- `use-review-agents.ts`: The review agents a review page can run, each one's newest run on the change, and running or cancelling one.
- `use-review-data.ts`: What a review page reads and writes: the diff, the comments and their writes, the picked slice of a split ticket, and the wording for the target.
- `use-review-grouping.ts`: The newest grouping by spec of the review, with starting and cancelling one.
- `use-review-jira.ts`: The Jira issues of a pull request under review: their text and comments, the suggestions, checking, linking, unlinking.
- `use-review-notion.ts`: The Notion pages of a pull request under review: their text, the description's suggestions, checking, linking one more and unlinking one.
- `use-review-preview.ts`: A pull request's preview as its Preview tab reads it (its checkout, its screenshots), and adding an output to the review.
- `use-review-report.ts`: The newest spec report of the review, with starting and cancelling one, adding its gaps to the review, and marking what needs the reviewer not useful.
- `use-review-specs.ts`: A review's specs (its Specs bar): the list as saved and read now, saving it, the specs the agents get, and a whole stack's for its agent review.
- `use-review.ts`: A pull request under review: its description and discussion, read from GitHub once per opening.
