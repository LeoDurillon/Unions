# Map: `apps/web/client/lib/review/`

The review's data and logic: API clients and hooks (specs, explanations, groupings, reports, agent reviews), diff selection and rows, file tree and filter, slices.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-review-api.ts`: API calls for a review's agent review, under the review's API root (`reviewBase`).
- `diff-selection.ts`: Which lines of a diff a comment covers: clicks, shift-clicks, whole hunks and whole files.
- `explanation-api.ts`: The explanation routes of a review, under its API root (`reviewBase`).
- `file-filter.ts`: Narrows the review's changed files: by words of their path (or their old path), and to the files Union counts as code.
- `file-tree.ts`: The files as a directory tree, for the review's file list.
- `flow-layout.ts`: Lays out a spec report's map in layers, top to bottom, each node ordered in its layer near the nodes it comes from.
- `line-diff.ts`: The lines of `after` against `before`: kept, added or removed, in reading order.
- `path-filter.ts`: Finds files by a few typed letters, like an editor's "go to file": the letters in order, anywhere in the path.
- `review-agents-api.ts`: API calls for a review's review agents: the agents it can run, each one's newest run, run one, cancel.
- `review-field-target.ts`: Where a property set from a review's tab goes: the review's route, its item's events, the tab's list of items.
- `review-grouping-api.ts`: API calls for a review's grouping by spec, under the review's API root (`reviewBase`).
- `review-report-api.ts`: API calls for a review's spec report, under the review's API root (`reviewBase`).
- `review-stack.ts`: The stack a pull request under review is in, for the review page's agent.
- `review-target.ts`: Where the target's diff, comments and send live; also the root of its query keys.
- `review-url.ts`: The review page's slice, section tab, diff lines and ticketless pull request in the URL, for Back, Forward and reload.
- `slice-view.ts`: Which comments a split ticket's review shows on each tab: a slice's on its own, the rest on All.
- `spec-hunks.ts`: What a file opened under a part of the spec shows: that part's hunks, and the parts each hunk serves.
- `split-rows.ts`: Pairs a patch's lines for side-by-side display.
- `use-agent-review.ts`: The latest agent review of the target, with starting and cancelling it.
- `use-explanations.ts`: The review's explanations, polled while one waits or runs, with asking, following up and cancelling.
- `use-review-agents.ts`: The review agents a review page can run, each one's newest run on the change, and running or cancelling one.
- `use-review-data.ts`: What a review page reads and writes: the diff, the comments and their writes, the wording for the target.
- `use-review-grouping.ts`: The newest grouping by spec of the review, with starting and cancelling one.
- `use-review-preview.ts`: A pull request's preview as its Preview tab reads it (checkout, screenshots), and adding an output to the review.
- `use-review-report.ts`: The newest spec report of the review, with starting and cancelling one and adding its gaps to the review.
- `use-review-specs.ts`: A review's specs (its Specs bar): the list as saved and read now, saving it, the specs the agents get.
- `use-review-tracker.ts`: The items of one tracker a pull request under review is linked to: their text and comments, the suggestions.
- `use-review.ts`: A pull request under review: its description and discussion, read from GitHub once per opening.
- `use-slice-view.ts`: The slice a split ticket's review page shows: its tabs, its target, its files and its comments.
- `viewed-files.ts`: Which files of a review the user marked viewed, remembered in this browser per review.
