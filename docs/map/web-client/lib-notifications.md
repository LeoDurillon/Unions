# Map: `apps/web/client/lib/notifications/`

Notifications in the browser: their API client and hook, groups, opening one, desktop notifications.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `desktop-notifications.ts`: Desktop notifications: off until the user turns them on, shown by the one tab that holds the event stream.
- `notification-groups.ts`: The notifications grouped by what they are about (a ticket or an investigation), newest group first.
- `notifications-api.ts`: The browser's client for the notifications: a page of them, marking them read and clearing them.
- `open-notification.ts`: Opens what a notification is about (its ticket or investigation, in its project) and marks it read.
- `use-notifications.ts`: The notifications, page by page, with how many are unread and how many still ask something, and their mutations.
