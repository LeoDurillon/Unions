# Map: `apps/web/client/lib/app/`

The app's frame: the `/api` client, the shared event stream and live invalidation, URL state and navigation, the active project and open ticket, the leave guard, help requests.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `api.ts`: The browser's client for the `/api` routes, and the errors they answer with.
- `event-hub.ts`: The browser's one shared event stream, handed to every listener in any tab.
- `help-requests.ts`: Help asked for from the sidebar's Help menu (the keyboard shortcuts, a project's getting-started checklist).
- `leave-guard.ts`: Unsaved settings: the forms holding changes, and asking before a navigation throws them away.
- `live-invalidation-keys.ts`: Which cached queries an event makes stale: board, ticket, investigations, notifications, the review page's side runs.
- `stream-status.ts`: Whether the live event stream is connected, for the sidebar's "Reconnecting…" pill.
- `url-state.ts`: Sets or removes (`null`) query parameters as one history entry, and tells every reader.
- `use-active-project.ts`: The project list plus the remembered selection, falling back to the first project.
- `use-app-state.ts`: What the root layout runs on: live refetching, the projects, the open ticket, navigation, and opening notifications.
- `use-event-stream.ts`: Calls `onEvent` with every new event, from the browser's one shared stream (`event-hub.ts`).
- `use-live-invalidation.ts`: Refetches board, ticket, investigation and notification data whenever the worker records a change.
- `use-navigation.ts`: Which page is shown (`?page=previews`, `?union=` for the Union settings, else the board) and which overlay is open.
- `use-project-view.ts`: Which view of the project shows: board, investigations, pull requests, repository, environments or usage.
- `use-selected-ticket.ts`: The open ticket, and whether its review is open, live in the URL (`?ticket=3&review=1`).
