# Map: `apps/web/client/components/repository/`

The repository browser: the file tree, the file viewer, refs and commits.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `commit-line.tsx`: The commit the Repository tab shows: its short sha (a link to GitHub), message, author and age, and Refresh.
- `file-header.tsx`: The open file's or folder's path, each folder of it a link up, with its size and the way to it on GitHub.
- `file-viewer.tsx`: The right side of the Repository tab: the picked file (text highlighted, or its size), or a folder's entries.
- `markdown-view.tsx`: A Markdown file of the repository rendered as GitHub shows it, or its source: its links open the repository's files in the tab, its images load from the reposi…
- `ref-picker.tsx`: The branch the Repository tab shows, as a button opening the repository's branches; a tag or commit can be typed too.
- `repo-filter.tsx`: The Repository tab's "go to file": a box that finds files by a few letters of their path, and the files found.
- `repo-tree-view.tsx`: The repository's folders and files; a folder unfolds on click, its entries drawn only once open.
- `repository-browser.tsx`: The Repository tab at one commit: the go-to-file box and the folders on the left, the picked file on the right.
- `repository-page.tsx`: A project's Repository tab: the whole repository at its base branch (or the branch in the URL), read from GitHub.
- `text-view.tsx`: A text file of the repository with its line numbers, highlighted for its language up to a few thousand lines.
- `use-repo-tree.ts`: The Repository tab's tree state: the folders open, and those read one at a time when GitHub truncated the tree.
