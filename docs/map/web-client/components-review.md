# Map: `apps/web/client/components/review/`

The review page: diffs and the file list, comments and threads, explanations, specs and grouping by spec, review reports, agent reviews, slices, sending the review.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `add-to-review.tsx`: Add to review on a tracker's comment (a Notion discussion, a Jira comment): a draft of the ticket's review, or why not.
- `agent-review-button.tsx`: Asks the review agent for draft comments on the change, and shows where it stands.
- `agent-review-dialog.tsx`: Review with agent: the review's specs, the scope (this pull request or the whole stack), and the start.
- `comment-card.tsx`: One comment: drafts can be edited or deleted, the agent's suggestions also kept as they are; sent ones are read-only.
- `comment-editor.tsx`: The editor under selected lines of the diff: a comment to add, or the lines to Explain with an optional question.
- `comment-thread.tsx`: The comments ending on one line, and the editor when the selection ends there.
- `commit-diff.tsx`: One commit of the change against its first parent (or the change since the last review), read only.
- `commit-picker.tsx`: All the changes, the change since the last review (tickets), or one commit: a button that opens the list.
- `copy-markdown-button.tsx`: "Copy as markdown": puts a text on the clipboard, and says "Copied" for a moment.
- `diff-area.tsx`: The whole change, or one of its commits or the change since the last review (read only), with the Explain panel.
- `diff-body.tsx`: The touched files on the left, the picked one on the right.
- `diff-link-code.tsx`: Inline code naming a file of the change (`path`, `path:12`, `path:12-30`) as a link that opens it in the diff.
- `diff-parts.tsx`: What both diff layouts share: line tones, the gutter, highlighted code, a hunk's spec tags and the comments on a line.
- `explain-context.tsx`: The review page's Explain state: the side panel, the specs an explanation is checked against, and the lines to show.
- `explain-panel.tsx`: The Explain side panel of the review: the specs explanations use, and the threads, newest first.
- `explanation-answer.tsx`: An explanation's answer: how the lines work with their cited code, the specs and docs they relate to.
- `explanation-card.tsx`: One explanation and its follow-ups: the lines asked about, their spec parts, each answer, and what to do next.
- `explanation-progress.tsx`: While an explanation waits or runs: its status, the agent's last steps (the files it reads) and Cancel.
- `file-diff.tsx`: One file's diff, unified or side by side; comments and the editor appear under the last line they cover.
- `file-filter-bar.tsx`: The box above the review's files that narrows them by words of their path (`/` goes to it).
- `file-list.tsx`: The touched files, as a list or a tree; ignored ones (lock files, project patterns) are listed apart, collapsed.
- `file-row.tsx`: One file of the review's list: whether it was viewed, its status, name, Key mark, drafts and line counts.
- `file-rows.tsx`: Files as a flat list of paths, or as a folder tree.
- `file-tree.tsx`: The files by directory; every directory starts open and folds on click.
- `general-comments.tsx`: Drafts about the whole change rather than lines of a file.
- `group-by-spec-button.tsx`: The file panel's "By spec" switch: shows the files under the parts of a specification.
- `group-by-spec-dialog.tsx`: Groups the change by the review's specs: they are read together, each a titled section.
- `hunk-focus.tsx`: A file opened under a part of the spec (By spec): only the hunks of that part, with a bar to show them all.
- `import-comments.tsx`: Pulls the linked pull request's unresolved review threads in as draft comments.
- `open-file-area.tsx`: The review diff's right side: the banner, errors, general comments and the open file.
- `open-file-header.tsx`: The open file's sticky header in the review: its path and line counts, Explain file, and Viewed (`v`).
- `open-file.tsx`: One file of the review: its header, its diff, the threads under their lines, and the outdated comments.
- `report-attention.tsx`: What needs the reviewer, at the top of the spec report: its items in order, or a word that nothing does.
- `report-body.tsx`: A finished spec report, in the order a reviewer uses it.
- `report-file-diff.tsx`: A file's diff with what the review's current spec report says about it.
- `report-flow-graph.tsx`: The spec report's map of how the change works, drawn: nodes in layers and the links between them with how.
- `report-flow.tsx`: How the change works, near the top of the spec report: the map of its main path, and the walkthrough.
- `report-header.tsx`: The top of a finished spec report: the verdict, the counts, its actions, the summary, and the specs it read.
- `report-important-files.tsx`: The report's files to read first, in order, each with why and its key lines; and the ones to skim, closed until clicked.
- `report-line-marks.tsx`: The lines of the open file that what needs the reviewer points at, for the diff's gutter to mark.
- `report-marks.tsx`: The files of the review's current spec report the file list marks (to read first, or to skim).
- `report-not-useful.tsx`: "Not useful" on an item of what needs the reviewer: hides it from the report and can keep a rule as a lesson.
- `report-open.tsx`: Links from the spec report to the diff: a file, its key lines as chips, opened in the Diff tab.
- `report-requirement.tsx`: One requirement of the spec report: its status, the spec's words, the note, the code and tests that do it.
- `report-requirements.tsx`: The spec report's requirements: the ones to check as cards, the ones done as asked closed until clicked.
- `report-sections.tsx`: The spec report's sections: the frame they share (a title with a count, rows in one box), then the last ones.
- `report-start.tsx`: Starts a spec report: what it does, the specs it will read (the Specs bar's), and Start.
- `report-tab.tsx`: The review's Report tab: the newest spec report, the agent writing one (with Cancel), or why the last one failed.
- `review-agent-run-card.tsx`: One review agent's newest run on the change: its state (Cancel while it works), why it failed, or its answer.
- `review-agents-tab.tsx`: The review's Agents tab: Run agent (the user's review agents, one run at a time on the change).
- `review-header.tsx`: The review page's header: Back, what is reviewed and at which commit, and how many files were viewed.
- `review-more.tsx`: The review header's ⋯ menu: what a reviewer needs now and then, kept out of the way.
- `review-page.tsx`: The review page, with what its parts share (the Explain panel, the specs dialog, the files marked viewed).
- `review-progress.tsx`: How far the reviewer got through the change: "12 of 300 files viewed" with a bar, from the files marked viewed.
- `review-providers.tsx`: What a review page shares across its parts: the Explain panel, the specs dialog, and the files marked viewed.
- `review-top.tsx`: The top of a review page: its header, then the review's specs.
- `send-review.tsx`: Sends the drafts and an optional overall note to the implementer, from a panel under the button.
- `slice-pick.tsx`: The slice a split ticket's review page shows, shared with its tabs so the PR tab follows the stack's tabs above.
- `slice-tabs.tsx`: A split ticket's slices as a segmented control under the review header.
- `spec-groups.tsx`: The files under the parts of the specification they implement, then the changes no part covers.
- `spec-picker.tsx`: Where a specification comes from: the PR description, the ticket, an issue, a Notion page, a Jira issue.
- `spec-row.tsx`: One spec in the specs dialog: its label and source, its text to read or edit, Use the source once edited, Remove.
- `spec-summary.tsx`: The specs an agent action will read, as a short list, with a link to edit them (the Specs bar's dialog).
- `specs-bar.tsx`: The review's specs under its header: one chip each (edited ones marked, unreadable ones in red), and Edit.
- `specs-dialog.tsx`: The review's specs to edit, saved on the review for Review with agent, Explain and Group by spec.
- `specs-editing.tsx`: Whether the review's specs dialog is open, shared by the Specs bar and the agent actions' dialogs.
- `split-diff.tsx`: Old file on the left, new on the right; removed and added runs face each other.
- `use-file-filter.ts`: The review's file filter: the letters typed, Not viewed and Code only.
- `use-file-keys.ts`: The review's file keys: j opens the next file, k the previous one, in the order the list shows them.
- `use-open-file.ts`: What the review's open file runs on: the file read, the selected lines and its comments.
- `view-toggle.tsx`: The Explain panel's toggle, then the Unified / Split switch for the review diff.
- `viewed-context.tsx`: The files of the review the user marked viewed, shared by the header's progress, the file list and the open file.
