# Map: `apps/web/client/components/steps/`

The Steps tab: a step's output, notices, review bar and answer form, verdict, start over, refused commits, the log, workspace commands and what their output becomes.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `answer-form.tsx`: The output with a text box in place of each `Answer:` line; answers can take several lines.
- `container-commands.tsx`: Commands the user runs in a workspace: a ticket's container as the agent, or a pull request's own checkout.
- `container-run-item.tsx`: One command run in a workspace, on one line: its exit, its command, how long; its output opens below.
- `log-line.tsx`: One line of an agent log: a tool call as its name and argument, the agent's words as prose, a run's end or error.
- `log-tab.tsx`: Replays the ticket's whole agent log, then follows it live.
- `refused-commit.tsx`: Shown on the step paused on a refused commit: the changes, the hook's output, the decision.
- `review-bar.tsx`: Approve, ask for a revision, or edit the output by hand (for example to answer questions).
- `run-agent-actions.tsx`: Giving a finished run's output to the implementer: kept for its next run, or sent now as a revision with a note.
- `start-over.tsx`: Start over: a planning or custom step runs again from scratch, after a confirmation.
- `step-notices.tsx`: What stops the step and needs the user: a failed run, a usage limit, a refused commit.
- `step-tab.tsx`: The ticket panel tab for one step: its output, verdict, answer form and review bar.
- `ticket-run-actions.tsx`: What a ticket's command output can become: kept for the implementer's next run, or sent now as a revision.
- `verdict-badge.tsx`: The reviewer's verdict at the top of the final review.
