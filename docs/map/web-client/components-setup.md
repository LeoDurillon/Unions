# Map: `apps/web/client/components/setup/`

The setup agent's proposal, reviewed and applied card by card.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `setup-agent-cards.tsx`: The setup proposal's tickets to create, and its questions, answered in a follow-up that asks for the proposal again.
- `setup-answered.tsx`: The Project setup card once the agent answered: what is left to apply, Review the setup, and its raw answer.
- `setup-card-props.ts`: What every card of a setup proposal gets: the project, the whole proposal, and its dismissed state.
- `setup-card.tsx`: One part of a setup proposal: why the agent proposes it, its values, and Apply or Dismiss until it is in the settings.
- `setup-cards.tsx`: The cards of a setup proposal's sections, in the order a project is set up: checks, scripts, preview, e2e, the rest.
- `setup-config-cards.tsx`: The setup proposal's saved scripts and agent image cards.
- `setup-preview-card.tsx`: The setup proposal's preview card: its compose file and additions to edit, the rest of its settings to read, then Apply.
- `setup-review.tsx`: The setup agent's proposal to review: summary and questions, a card per section to apply, the tickets it asks for.
- `setup-start.tsx`: Starts the setup agent again: the model to run with, and a Start that says it uses the Claude subscription.
- `setup-status.tsx`: The setup agent's run above a project's board: reading the repository, its proposal, or why it failed.
- `setup-text-cards.tsx`: The setup proposal's cards made of commands and text: the checks, the e2e command and the project instructions.
- `setup-todo-cards.tsx`: The setup proposal's to-dos: secret values and files only the user can give.
- `setup-values.tsx`: Small views the setup cards share: a field with the value now in the settings under it, and a labelled list.
