# Map: `apps/web/client/lib/log/`

A Log's data: polling it, the agents' stream-json condensed into lines, runs folded apart, token counts, runs in progress.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-events.ts`: Condenses one raw `claude -p` stream-json event into zero or more log lines.
- `log-calls.ts`: Pairs each tool result with its call in a Log: the call's row gets the output, the result's own line goes.
- `log-runs.ts`: Splits the log at each run header, so every run can fold on its own.
- `strip-ansi.ts`: Removes the terminal's colour and cursor codes from output shown as plain text.
- `token-counts.ts`: A call's tokens as the Log shows them, from its `result` event: input with its cached share, output with its thinking.
- `use-log.ts`: Polls a ticket's or an investigation's Log while it is shown: all of it first, then what is new.
- `use-run-progress.ts`: The project's runs in progress: when each started and what its agent did last.
