# Map: `apps/web/client/components/previews/`

Previews: a ticket's or pull request's preview section and tab (controls, output, compose file, reset, e2e), and the running previews page.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `preview-compose-dialog.tsx`: The compose file a preview runs, to read and to edit for this ticket or pull request.
- `preview-controls.tsx`: The preview's addresses and buttons: Start (Cancel while it starts; Restart, data kept, and Stop while it runs).
- `preview-e2e-result.tsx`: The last end-to-end result in a few words, and its output and command, folded.
- `preview-e2e.tsx`: The project's end-to-end tests against the preview, run only when the user asks, never on their own.
- `preview-heading.tsx`: The preview's title line: its status, how long a start has run, and the less frequent actions.
- `preview-output.tsx`: What a preview printed: its start as it goes (a ticket's), and its services' last lines.
- `preview-reset.tsx`: The preview's Reset: drops its containers, volumes and built images, and the data folders the user ticks.
- `preview-section.tsx`: A ticket's or a pull request's preview: its compose environment run from the workspace, opened through the proxy.
- `preview-summary.tsx`: The preview in one line of the Overview: its state, where it answers, the way to its tab.
- `preview-tab.tsx`: The ticket's Preview tab: the environment, its output, its end-to-end tests, and commands.
- `previews-button.tsx`: The sidebar's Previews entry: how many previews hold containers now, across projects.
- `running-preview-row.tsx`: One preview holding containers: its state, the ticket or pull request it is for, its addresses, and Stop.
- `running-previews-page.tsx`: Every preview holding containers, across projects, grouped by project: where it answers, whose it is, and Stop.
- `ticket-e2e-actions.tsx`: What a ticket's failing end-to-end run can become: a revision the implementer gets, like a failing check.
