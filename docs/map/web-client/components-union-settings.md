# Map: `apps/web/client/components/union-settings/`

The Union-wide settings: models, resources, custom agents, and their nav.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-kind-field.tsx`: Where a new custom agent runs, chosen once: a step of ticket flows, or a review agent run from a review page.
- `agent-row.tsx`: One row of the All agents table: the agent's name (opening its page), its model and effort.
- `models-page.tsx`: All agents in one table: each one's model and effort with one Save, whether it was customized, and a link to its page.
- `new-agent-dialog.tsx`: Creates a custom agent from its kind, a name and a role; the worker then writes its prompt, and its page opens.
- `resources-page.tsx`: Union settings → Resources: each container's memory and CPU cores, and how many agent runs and previews at once.
- `system-page.tsx`: Union settings → System: how often GitHub is read, the largest project file, and the images Union runs.
- `union-nav-groups.ts`: The Union settings menu: the shared instructions, All agents (and the agent page open), Tools and the GitHub App.
- `union-other-pages.tsx`: The Union settings pages that are not an agent's: All agents, Resources, System, Tools, Connectors and the GitHub App.
- `union-section-body.tsx`: The open Union settings page: an agent's, or another (all agents, resources, tools, connectors, the GitHub App).
- `union-section-labels.ts`: The names the Union settings menu shows: each agent's title, then the other pages'.
- `union-settings-fields.tsx`: The inputs of the Union settings pages: a whole number with its unit and bounds, and an image name.
- `union-settings-loader.tsx`: A Union settings page that edits the machine settings: its intro, then its form once they are read.
- `union-settings-nav.tsx`: The Union settings menu: the shared instructions, All agents, Tools, the GitHub App, and New agent.
- `union-settings-page.tsx`: The settings every project shares: a page per agent, the tools, the GitHub App (`?union=`).
