# Map: `apps/web/client/lib/setup/`

The setup agent in the browser: its API, follow-up, applying a proposal's parts, dismissed ones.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `setup-api.ts`: The browser's client for the setup agent: its latest run with the proposal and checks, starting one, testing values.
- `setup-follow-up.ts`: The follow-ups that ask the setup agent for its whole proposal again: with answers to its questions, or a failed check.
- `use-setup-apply.ts`: Applying one part of a setup proposal through the endpoint its settings page uses, then reading the settings again.
- `use-setup-check.ts`: A setup card's Test again and Ask the agent to fix: the worker checks the card's values, or the agent gets the failure.
- `use-setup-dismissed.ts`: The parts of a setup proposal the user dismissed, remembered per setup run in this browser.
