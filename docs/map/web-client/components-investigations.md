# Map: `apps/web/client/components/investigations/`

Investigations: their page and list by week, header, form, conversation and tabs, export, and the tickets written from them.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `investigation-actions.tsx`: An investigation's buttons: Cancel or Run again, Export as Markdown, and Delete.
- `investigation-detail.tsx`: One investigation: its header, the ticket being written from it (or the form asking what it covers), then its tabs.
- `investigation-export.ts`: An investigation as a Markdown file: its settings, then every question and its answer, oldest first.
- `investigation-form.tsx`: A new investigation: what to look into, where, and with which model and tools.
- `investigation-header.tsx`: The top of an open investigation: its title and state, where it ran (scope, model, questions, tools), its actions.
- `investigation-labels.ts`: The labels and badge tones the investigations pages show for each status and scope.
- `investigation-list.tsx`: The investigations beside the open one: New, a search, then the investigations by week.
- `investigation-tabs.tsx`: An investigation's tabs: the conversation, the agent's live log, and what its agent calls used.
- `investigation-thread.tsx`: An investigation as a conversation, oldest first: questions in bubbles, answers in cards, then the follow-up box.
- `investigation-ticket.tsx`: Turns the investigation into a backlog ticket written by an agent: the header's buttons and the form under it.
- `investigations-page.tsx`: Ad-hoc agent runs on a custom prompt for the project; no GitHub issue is created.
- `scope-field.tsx`: Repository (with the clone's name), a ticket's workspace (with the ticket), or a global subject.
- `ticket-picker.tsx`: The project's tickets that have a workspace to read (not cancelled), newest first.
