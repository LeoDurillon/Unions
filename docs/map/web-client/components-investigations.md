# Map: `apps/web/client/components/investigations/`

Investigations: their page, form, thread, detail and export, and the tickets made from them.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `investigation-actions.tsx`: An investigation's buttons: Cancel or Run again, Export as Markdown, and Delete.
- `investigation-detail.tsx`: One investigation: its header, the ticket being written from it (or the form asking what it covers), then its tabs: the conversation with the follow-up box, the agent's live log, and what its agent calls used.
- `investigation-export.ts`: An investigation as a Markdown file: its settings, then every question and its answer, oldest first.
- `investigation-form.tsx`: A new investigation: what to look into, where, and with which model and tools.
- `investigation-header.tsx`: The top of an open investigation: its title and state, where it ran (scope, model, questions, tools), and its actions: Run again or Cancel, Export, Delete, Open ticket and Write a ticket from it.
- `investigation-labels.ts`: The labels and badge tones the investigations pages show for each status and scope.
- `investigation-list.tsx`: The investigations beside the open one: New, a search, then the investigations by week, each with its state (a dot), its scope, the ticket written from it and its date.
- `investigation-tabs.tsx`: An investigation's tabs: the conversation (with the follow-up box once answered), the agent's live log, and what its agent calls used.
- `investigation-thread.tsx`: An investigation as a conversation, oldest first: each question in a bubble, each answer in a card (the latest one whole, or why there is none yet), then the box that asks a follow-up.
- `investigation-ticket.tsx`: Turns the investigation into a backlog ticket written by an agent: the header's buttons (Open ticket, Write a ticket from it), then under it the form asking what the ticket covers, the ticket being written, or why it failed.
- `investigations-page.tsx`: Ad-hoc agent runs on a custom prompt for the project; no GitHub issue is created.
- `scope-field.tsx`: Repository (with the clone's name), a ticket's workspace (with the ticket), or a global subject.
- `ticket-picker.tsx`: The project's tickets that have a workspace to read (not cancelled), newest first.
