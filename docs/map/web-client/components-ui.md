# Map: `apps/web/client/components/ui/`

Shared UI pieces: buttons, badges, fields and dialogs, choice inputs, code textarea, confirm button, dropzone, help text, icon buttons, overflow menu, tabs, detail rows.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `choice.tsx`: The app's choice inputs: chips for a multi-select, a switch for on / off, a segmented control for one of a few.
- `code-textarea.tsx`: A monospace textarea that colours its text for a language (Dockerfile, YAML).
- `confirm-button.tsx`: A destructive action that asks first: a quiet red button, then the question with confirm and keep.
- `detail-row.tsx`: One entry of a ticket's details, in the Overview's side column: a small label above its value.
- `dropzone.tsx`: A file input as a dashed box: drop files on it, or click (or press Enter on it) to browse.
- `help-text.tsx`: Help under a control: its first sentence, the rest behind "more", so long explanations do not bury the controls.
- `icon-button.tsx`: Small icon-only buttons for row actions (edit, delete, move, done), and their icons.
- `overflow-menu.tsx`: A "⋯" button opening a short list of less frequent actions; a choice, Escape or a click outside closes it.
- `tab-button.tsx`: A tab of a tab bar (`role="tab"`): underlined when selected.
- `ui.tsx`: Shared UI pieces: buttons, badges, fields, text inputs, error text and dialogs.
