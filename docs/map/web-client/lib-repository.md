# Map: `apps/web/client/lib/repository/`

The Repository tab's data: its API, tree, links to GitHub, relative paths, and its place in the URL.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `readme.ts`: Which file of a folder is its README, shown under the folder's entries as GitHub does.
- `repo-links.ts`: Where a file or folder of the repository is on GitHub, and a file's size in words.
- `repo-paths.ts`: Where a relative link in a repository file points: `../docs/a.md` from `src/README.md` is `docs/a.md`.
- `repo-tree.ts`: The repository's entries as folders, each with its children in the order the tree shows them.
- `repository-api.ts`: The Repository tab's reads: the commit a branch names, the tree at it, one file.
- `repository-url.ts`: The Repository tab in the URL (`?view=repository&repo-ref=main&repo-path=src/a.ts`).
