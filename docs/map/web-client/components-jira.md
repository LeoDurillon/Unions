# Map: `apps/web/client/components/jira/`

A ticket's Jira tab: its comments and replies.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `jira-comment.tsx`: One comment of a ticket's Jira issue: who wrote it and when, who may see it, its text, where it is in Jira, and what can be done with it (Reply).
- `jira-reply.tsx`: A new comment on a ticket's Jira issue, or a reply to one (it mentions the author): what is being sent, then a button that opens the box.
- `jira-tab.tsx`: A ticket's Jira tab: the comments of the issue it was imported from, read once per opening, with Refresh, Reply on each and New comment, which the worker posts.
