# Map: `apps/web/client/components/environments/`

A project's Environments tab: the preview settings (compose, services, variables, secrets, limits, e2e, agent) and the shared services.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-variables-field.tsx`: Which of the preview's plain variables the agent's commands get (and the commands the user runs).
- `environment-section-body.tsx`: The page of the Environments tab the URL names, one per part of how the previews run.
- `environment-summary.tsx`: The top of the Environments tab: the project's previews at a glance.
- `environments-page.tsx`: The project's Environments tab: its previews at a glance, what runs now, and how its previews run.
- `preview-agent-page.tsx`: What the agent gets from the preview's environment: services, variables, ports, and the preview itself.
- `preview-choices-field.tsx`: A choice among names the compose file has (profiles, services).
- `preview-compose-page.tsx`: What runs as a ticket's preview: the compose file, what Union adds to it, and its profiles.
- `preview-e2e-page.tsx`: The command a ticket's Preview section runs on request against its preview.
- `preview-fields.tsx`: Compose YAML merged over the repository's file, for what Union adds without changing the repository.
- `preview-form.tsx`: The page's form, from the saved settings; its Save writes the whole configuration.
- `preview-limits-page.tsx`: How long a preview nobody visits keeps running, and how many of the project's run at once.
- `preview-secrets.tsx`: The project's secret variables: written here, never shown again.
- `preview-services-field.tsx`: The services the proxy serves: name in the compose file, port, and host prefix.
- `preview-shared-page.tsx`: The services the project's previews share, run once instead of in each preview.
- `preview-variables-page.tsx`: What every service of a preview gets: plain variables, secrets, and the variables as a file.
- `project-previews.tsx`: The project's previews that hold containers now, tickets' and pull requests', with Stop.
- `set-up-services-first.tsx`: What a page of the Environments tab shows before the project's previews are set up: the way to Compose.
- `shared-commands-field.tsx`: The services shared between previews and, per service, the commands that keep each preview's data apart there.
- `shared-links.tsx`: The addresses of the shared services the proxy opens (`s3-p1.union.localhost`), as links.
- `shared-services-status.tsx`: The project's shared services now: whether they run, which previews and agents use them, and Restart and Stop.
- `use-compose-services.ts`: What the compose file of the project's latest preview offers (its services and profiles).
