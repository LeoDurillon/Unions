# Map: `apps/web/client/lib/preview/`

Previews in the browser: API client, status, hooks for a preview, the running ones and the shared services.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `preview-api.ts`: The browser's client for a ticket's preview endpoints.
- `preview-status.ts`: How a preview's status reads on its badge, wherever it shows.
- `preview-target.ts`: Where a ticket's or a pull request's preview and commands live in the API, and their query keys.
- `use-preview.ts`: A ticket's or a pull request's preview as its section reads it, and the commands that act on it.
- `use-running-previews.ts`: The previews running across projects (read again every few seconds: a pull request's send no events), and stopping one.
- `use-shared-services.ts`: The project's shared services as the worker last saw them (read again every few seconds: they send no events), and asking it to restart or stop them.
