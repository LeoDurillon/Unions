# Map: `apps/web/client/components/pull-request/`

A ticket's pull request: branch status and actions, CI checks, discussion and replies, description, the stack and splitting it, simplifying history.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `branch-actions.tsx`: Where the pull request's branch stands against its base and against GitHub, and rebasing or resyncing it.
- `branch-moved.tsx`: The notice that the branch moved on GitHub since Union pushed it, and the button that resyncs Union's copy onto it.
- `branch-status.tsx`: How far the PR's branch is behind its base (polled from GitHub by the worker) and the Rebase button.
- `change-target.tsx`: Change target: the finished ticket's own commits moved onto another branch, and its pull request retargeted there.
- `ci-check-rows.tsx`: One line per CI check or bot comment of the pull request, with a box to pick it for the implementer.
- `ci-checks.tsx`: The pull request's CI checks on its last commit, and its bot comments.
- `ci-given.tsx`: The CI output given to the implementer: waiting for its next run (it can be taken back) or read.
- `ci-pick-actions.tsx`: The picked checks, jobs and comments: read the text the agent would get, keep it for its next run, or send it now.
- `comment-body.tsx`: A GitHub comment's text in compact markdown, folded behind a fade when it renders tall.
- `description-draft.tsx`: The rewritten description, editable, with what it changes on GitHub a click away.
- `discussion.tsx`: The pull request's GitHub discussion (`pr`: the ticket's or a slice's), and what of it goes to the implementer.
- `followed-base.tsx`: The notice that GitHub moved the pull request off its base: the next rebase leaves that base's commits behind.
- `github-description.tsx`: A pull request's description as GitHub has it now, folded when long: the same for the ticket's PR and each slice's.
- `more-actions.tsx`: The branch operations of an open pull request, folded under "More actions" above the CI checks.
- `note-card.tsx`: A review summary or a conversation comment, with its Add to review action when there is one.
- `note-filter.tsx`: Whose reviews and comments the discussion shows: everyone's, people's only, or bots' only.
- `pr-description.tsx`: A pull request's description: GitHub's text, and the agent's rewrite of it to edit and send.
- `pull-request-sections.tsx`: The PR tab's sections about one pull request: CI checks, description, discussion.
- `reply-area.tsx`: Under a thread or a note: the replies being posted, the implementer's suggested reply, and Reply or Quote reply.
- `reply-box.tsx`: The box a reply to a pull request comment is written in: its text, Resolve for a thread, who posts.
- `rewrite-descriptions.tsx`: A split ticket's Rewrite all descriptions: the agent rewrites each open slice's, one after the other.
- `simplify-history.tsx`: The Simplify history button: the implementation agent rewrites the branch's commits, the code unchanged.
- `slice-ci.tsx`: A slice's CI in one word (failed, running, passed), its counts by state on hover.
- `split-stack.tsx`: The Split into a stack button: an agent plans slices of the spec, then the branch becomes a stack of pull requests.
- `stack-actions.tsx`: What can be done to a split ticket's whole stack: Rebase stack, Restack, Simplify history, Split again.
- `stack-panel.tsx`: A split ticket's stack in its PR tab: one line per slice with its CI, what went wrong, and what can be done to it.
- `stack-pr-picker.tsx`: Which pull request of a split ticket's stack the PR tab's checks, description and discussion are about, bottom first.
- `stack-slice-row.tsx`: One slice of a split ticket's stack on one line: its pull request (linked), state, CI and title; its branch on hover.
- `suggested-reply.tsx`: The implementer's suggested reply under a thread or note (edit, send, discard), and a reply being sent.
