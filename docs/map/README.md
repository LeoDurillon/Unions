# Map of the repository

Find the folder of what you change below, then read its map: one line per file, from the file's top `//` comment. To find a word in every map: `grep -rn <word> docs/map`.

Generated by `bun run map`; do not edit. Tests are left out.

## core: `packages/core/src`

- [`./`](core/root.md), 6 files: The package entry and what every part shares: the public API, the database, the tables, the ticket state machine and its phases.
- [`agent/`](core/agent.md), 12 files: The agents' defaults and how a run resolves them: prompts, models, tools, denied commands, environment, connectors, log, answer formats.
- [`custom-agents/`](core/custom-agents.md), 4 files: Custom agents: their records, defaults, what still uses them, and the prompt writer that writes their instructions.
- [`diff/`](core/diff.md), 6 files: Diffs: parsing, hunks, excerpts, the links agents cite, and change size against the budget.
- [`docker/`](core/docker.md), 11 files: Docker: the `ContainerRuntime` interface and the `docker` CLI behind it, helper containers, limits, compose containers, the projects' agent images.
- [`event/`](core/event.md), 11 files: Event rules: the events catalog and payloads, the rules and their actions (Jira, Notion, GitHub Project fields, pull requests), cursors and deliveries.
- [`flow/`](core/flow.md), 5 files: Ticket flows: the steps a ticket runs, the project's presets, editing them, step titles.
- [`github/`](core/github.md), 9 files: GitHub: auth and clients, the optional layers (Project, issues), Project fields, text, issue step comments, file blobs, half-sent recovery.
- [`integrations/`](core/integrations.md), 47 files: Jira and Notion: their API clients, configs and providers, comments and media, and the conversions between Markdown and Atlassian Document Format or Notion blocks.
- [`investigation/`](core/investigation.md), 3 files: Investigations: their records, defaults, and the tickets written from them.
- [`lessons/`](core/lessons.md), 6 files: The project's memory: lessons and feedback, the lesson writer and tidier, their prompts and queue.
- [`preview/`](core/preview.md), 16 files: Previews: records, the compose file and its checks, config, memory caps, secrets, e2e screenshots and staleness, workspace owner, shared services.
- [`pull-request/`](core/pull-request.md), 8 files: A ticket's pull request: description rewrites, comment replies, review verdicts, branch moves on GitHub, the followed base, resumed-implementer prompts.
- [`review/`](core/review.md), 15 files: Reviews: agent reviews and their runs, specs and spec sources, explanations, groupings by spec, review reports, the run lifecycle.
- [`schema/`](core/schema.md), 31 files: The Drizzle schema, one file per group of tables, and their shared column types.
- [`setup/`](core/setup.md), 8 files: The setup agent offered at the end of the wizard: its prompt, its proposal's parts and preview, and applying it.
- [`stack/`](core/stack.md), 9 files: Stacks of pull requests: GitHub stacks, the split plan, slices, trailers, restack todos, status, descriptions and state-machine moves.
- [`ticket/`](core/ticket.md), 15 files: Tickets: records and dispatch, links and base, Needs you, start over, attachments, project files and scripts, command and CI outputs, refused commits.
- [`union/`](core/union.md), 5 files: Union itself: machine settings, its update, the work a restart interrupts, notifications.
- [`usage/`](core/usage.md), 16 files: Agent usage: tokens and tool calls recorded from the log, Claude limits, totals and summaries, findings, and the "Suggest improvements" prompt.
