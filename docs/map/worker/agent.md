# Map: `apps/worker/src/agent/`

Running `claude` in a container: idle detection and rate limits.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-idle.ts`: Stops a `claude` process that ended its turn, with no background task left, but does not exit.
- `agent.ts`: Runs `claude -p` inside the ticket's container and streams its events to `onEvent`.
- `rate-limit.ts`: Tells a usage limit from other agent errors, and when the limit resets: from the CLI's event, else its message.
