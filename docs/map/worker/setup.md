# Map: `apps/worker/src/setup/`

Checking a setup agent's proposal without Claude: its install and check commands run, its preview resolved.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `setup-check-commands.ts`: Runs a setup proposal's install command, then its check command, each with its own timeout, as the card's stages.
- `setup-check-run.ts`: Runs one check of a setup proposal in a throwaway container without the Claude login, on a fresh clone.
- `setup-checker.ts`: Runs the queued checks of setup proposals, two at a time, each in its own throwaway container; no Claude usage.
- `setup-preview-check.ts`: Checks proposed preview settings on a fresh clone as Start would, without a ticket and without starting anything.
