# Map: `apps/worker/src/investigation/`

Investigations: running one, and turning it into tickets.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `investigate-ticket.ts`: Runs a `ticket` investigation in the ticket's own container, on the workspace as the agent left it.
- `investigate.ts`: Runs queued investigations, each in a throwaway container (`union-i<id>`), and builds their prompt.
- `investigation-ticket-target.ts`: Creates a ticket drafted from an investigation as an item of the tracker the user picked too (a Notion page, a Jira issue).
- `investigation-ticket.ts`: Writes the tickets asked from investigations, each in a throwaway container removed afterwards.
