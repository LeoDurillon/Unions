# Map: `apps/worker/src/agent-image/`

Building and checking the projects' own agent images.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `build.ts`: Makes a project's agent image from what the user saved: the Dockerfile built on the base images, or the image pulled.
- `check.ts`: Checks that a project's agent image still has what Union's agents need.
- `images.ts`: The projects' own agent images in the worker.
- `output-log.ts`: A build's output lines, written to its row at most once a second and at the end.
