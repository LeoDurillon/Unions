# Map: `apps/worker/src/review/`

Review side runs: agent reviews, explanations, groupings by spec, review reports.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `agent-review-ask.ts`: Runs one agent of an agent review, its lines logged under the review, and reads its findings.
- `agent-review-change.ts`: The agent review of one change, a ticket's or a pull request's: its prompt, and what of the change it opened.
- `agent-review-checkout.ts`: Opens the change an agent review reads: one change (a ticket's or a pull request's) or a stack, with its prompt.
- `agent-review-cut.ts`: Cuts the change of a sliced agent review: from the grouping by spec of its head, one run now, or by folder.
- `agent-review-findings.ts`: The agent review's answer format, and its findings read back as draft comments.
- `agent-review-merge.ts`: Merges a sliced review's findings: each slice's, then the seams', duplicates kept once, into one answer.
- `agent-review-slice-prompt.ts`: The prompts of a sliced agent review: one agent per slice of the change, then one on how the slices fit.
- `agent-review-sliced.ts`: Runs a sliced agent review: cuts the change, one agent per slice in turn, one on the seams, then merges.
- `agent-review-stack.ts`: A stack's agent review: its pull requests checked out together, and the prompt that lists them.
- `agent-review-target.ts`: Checks out the change an agent review reads: the ticket's branch, or a pull request in a throwaway container.
- `agent-review.ts`: Runs queued agent reviews of a ticket's change or a pull request, sharing the run slots with the pipeline.
- `engine.ts`: One runner for the review side runs: claims within the run slots, checks the change out, runs the kind's work.
- `hunk-index-file.ts`: Runs a review agent's work on the change's files with their hunk index written in the checkout.
- `names.ts`: The throwaway container of a review side run on a pull request: one letter per kind.
- `outcome-text.ts`: How a review side run says the agent's answer lacks the block it was asked for, with the answer's end.
- `review-agent-checkout.ts`: A review agent's change in its own throwaway container (`union-v<id>`).
- `review-agent-prompt.ts`: A review agent's prompt: the instructions and its lessons, its own prompt, the review's specs, the change.
- `review-agent-run.ts`: Runs the review agents the user asked for on a review's change.
- `review-agent-setup.ts`: Prepares a review agent's checkout before it runs: the project's files and its install command.
- `review-change-prompt.ts`: The part of a review agent's prompt that says where the change is and how to read it.
- `review-explain-prompt.ts`: The prompts of an Explain: a fresh one with the specs, the change and the lines, and a follow-up's.
- `review-explain-result.ts`: Reads the explanation block at the end of the agent's answer, and drops the citations it cannot back.
- `review-explain.ts`: Explains a review's lines as users ask, one per review at a time.
- `review-grouping-format.ts`: What the grouping agent reads and answers in: the diff's hunks, one per line, and the answer's block.
- `review-grouping-prompt.ts`: The grouping agent's prompt: the specification, the change and the answer's format.
- `review-grouping-result.ts`: The agent's grouping, checked against the change: only changed files and their real hunks, every hunk at least once.
- `review-grouping.ts`: Groups a review's files by spec, as the user asked.
- `review-report-ask.ts`: Asks the report agent and reads its report, asking once more in the same session when the answer has no block.
- `review-report-checkout.ts`: Reads in the container what the report is checked against: the files it names and the change's commit messages.
- `review-report-fields.ts`: Reads the fields of the report agent's block: texts, lists, enums, paths and line ranges, never trusted.
- `review-report-flow.ts`: The report's map of how the change works, read from the agent's block: nodes, edges and a walkthrough.
- `review-report-format.ts`: What the report agent reads and answers in: the specs, numbered, and the answer's block.
- `review-report-items.ts`: The report's lists read from the agent's block: requirements, the important files, the risks and the docs.
- `review-report-prompt.ts`: The prompts of a spec report: the first one with the specs and the change, and one more turn asking for the block.
- `review-report-result.ts`: Reads the report block ending the agent's answer: quotes checked against the specs sent, paths against the change.
- `review-report-scope.ts`: What the change does that no requirement asked for: the agent's list, checked against the diff.
- `review-report-triage.ts`: The report's triage read from the agent's block: what needs the reviewer, and the files they can skim.
- `review-report.ts`: Writes the spec reports the user asked for.
- `review-runs.ts`: Runners of the review page's agents: agent reviews, spec groupings, line explanations, spec reports, review agents.
