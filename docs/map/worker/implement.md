# Map: `apps/worker/src/implement/`

The implementation step: its loop, checks, prompts and size trimming.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `implement-checks.ts`: The checks after an agent turn (install, then the project's check); `retry` is what the session is sent when they are red.
- `implement-loop.ts`: Agent turn, then checks; on red checks the same session gets the failure, up to the limit.
- `implement-prompts.ts`: The implementer's prompts past the first: check and preview hints, feedback, failed checks, given outputs, and its report.
- `implement-run.ts`: The implementation before it is published: the agent's turns and the checks, or the end of a run paused on a refused commit.
- `implement.ts`: Implements the approved plan on the ticket's branch, checks it, pushes it, opens the draft PR.
- `size-trim.ts`: Measures an implementation against its size budget and, when a first one went too far over, sends the implementer's session back once to cut it.
