# Map: `apps/worker/src/pull-request/`

Pull requests: adopting one, checking it out, writing its description, suggesting replies.

Generated by `bun run map`; do not edit. Tests are left out. All folders: [the index](../README.md).

- `pr-adopt.ts`: A ticket imported from a pull request: its branch checked out in the ticket's container and its diff captured.
- `pr-checkout.ts`: Checks pull requests out at their reviewed commits: the host clones and fetches, the container gets the files.
- `pr-description-run.ts`: Rewrites a pull request description in the ticket's container, from the template and the change.
- `pr-description-runner.ts`: Runs queued rewrites of pull request descriptions.
- `pr-description.ts`: Asks the implementer for a pull request's description (from the repository's template, if any) and reads it back.
- `pr-reply-format.ts`: The replies turn's prompt (the comments to answer) and answer format, and its answer read back as one reply per comment.
- `pr-reply-suggestions.ts`: After a revision is pushed, asks the implementer for a reply to each comment imported from GitHub it worked on.
